Into the Dead: Our Darkest Days - 간편 도구 (지도 랜덤 배치 + 반경 1.5배 / 사용자 지정 시나리오 프리셋)

[무엇이 바뀌나요 - 메뉴 1번에서 항목을 골라 적용]
- 항상 적용: 은신처 주변 탐색 범위(지도의 원)가 1.5배로 넓어집니다.
- 지도 랜덤 섞기 (선택): 지도의 건물/장소 위치가 무작위로 섞입니다 (은신처, 상인, 스토리 장소는 제자리).
- 밸런스 묶음 (선택): 총알 산출량 x5, 생존자 가방 24칸, 지도 스테이션 2칸, 시체 회수 24칸, 미스터 베일 신규 품목 순서(석궁/샷건 번갈아).
- 탈출 퀘스트 단서 (선택): 탈출 퀘스트를 열기 위해 조사해야 하는 장소 수를 3곳에서 1곳으로 줄입니다.
- 항목은 y/n 으로 고르고, 엔터를 누르면 지난번에 고른 값이 그대로 쓰입니다.
- 주의: 이 도구는 항상 원본에서 다시 계산합니다. 전에 적용했던 항목을 이번에 n 으로 두면 그 항목은 원래대로 돌아갑니다.

[사용법 - 3단계]
1. 받은 zip 을 풀면 ItD_MapMod.exe 가 나옵니다 (바탕화면 등 아무 곳에 두면 됩니다).
2. 게임과 스팀을 완전히 끕니다.
3. ItD_MapMod.exe 를 더블클릭 -> 1번 -> 항목을 y/n 으로 고르고 -> y 를 누릅니다. "끝!" 이 나오면 스팀에서 새 게임을 시작하세요.

[사용자 지정 시나리오 프리셋 (메뉴 4번)]
게임의 사용자 지정 시나리오 화면에는 쉬움/보통/어려움 프리셋이 있습니다. 그 칸의 값을 내 설정으로 바꿔 두면, 게임 안에서 그 프리셋을 고르는 것만으로 내 설정이 한 번에 불러와집니다.
1. 게임에서 사용자 지정 시나리오 설정을 원하는 대로 맞추고 새 게임을 시작해 한 번 저장(자동저장 포함)합니다.
2. 게임을 끄고 ItD_MapMod.exe -> 4번 -> 1번: 세이브에서 내 설정을 읽어 이름을 붙여 저장합니다 (presets 폴더에 파일로 보관되어 공유/백업도 가능).
3. 4번 -> 3번: 저장한 프리셋을 쉬움/보통/어려움 칸 중 하나에 넣습니다. (그 칸의 원래 값은 사라집니다. 4번 메뉴의 4번으로 원래대로 되돌릴 수 있습니다.)
4. 게임을 켜고 새 사용자 지정 시나리오 화면에서 그 칸의 프리셋을 고르면 값이 들어갑니다.
- 칸의 이름은 그대로 쉬움/보통/어려움으로 보입니다 (이름 문자열은 게임 코드/번역 파일 쪽이라 바꾸지 않았습니다).
- 쉬움/보통/어려움 프리셋이 쓰이는 다른 화면에서도 같은 값이 쓰일 수 있습니다.
- 프리셋 파일(presets\*.json)은 메모장으로 열어 값을 직접 고칠 수도 있습니다. 허용되지 않는 값은 적용할 때 걸러냅니다.

[꼭 알아두세요]
- 반드시 새 게임을 시작하기 전에만 적용하세요. 진행 중인 세이브에는 쓰지 마세요 (지도가 달라집니다).
- 다시 1번을 실행하면 지도가 새로 섞입니다. 2번(시드 지정)에 같은 숫자를 넣으면 같은 지도가 나옵니다.
- 게임이 업데이트되면 같은 방법으로 다시 실행하세요.
- 원래대로: ItD_MapMod.exe -> 3번. (원본은 게임 폴더의 AssetBundles\_mods_backup 에 자동 백업됩니다.)

[필요한 것]
- Windows 64비트 PC 와 스팀에 설치된 게임. 그 외에는 아무것도 필요 없습니다 (Python, 인터넷 불필요).
- 게임 폴더는 자동으로 찾습니다. 못 찾으면 경로를 붙여넣으라고 물어봅니다.
- 처음 실행할 때 윈도우가 "PC를 보호했습니다 / 알 수 없는 게시자" 경고를 띄울 수 있습니다.
  서명이 없는 개인 제작 프로그램이라 나오는 경고입니다. "추가 정보" -> "실행" 을 누르면 됩니다.
  백신이 막으면 이 파일을 예외로 두거나, 믿기 어려우면 사용하지 마세요.

[문제가 생기면]
- 화면 메시지와 같은 폴더의 exe 와 같은 폴더에 생기는 apply_all.log 를 보내 주세요. 실패하면 게임 파일은 바뀌지 않습니다.
- 게임 파일을 수정하는 비공식 도구입니다. 사용은 본인 책임이고, 이상하면 3번(되돌리기) 또는 스팀의 "게임 파일 무결성 검사"로 원상복구됩니다.
