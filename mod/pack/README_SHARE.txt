Into the Dead: Our Darkest Days - 지도 수정 (랜덤 지도 배치 + 탐색 반경 1.5배)

[무엇이 바뀌나요]
- 지도의 건물/장소 위치가 무작위로 섞입니다 (은신처, 상인, 스토리 장소는 제자리).
- 은신처 주변 탐색 범위(지도의 원)가 1.5배로 넓어집니다.
- 그 밖의 것(총알, 가방, 상점 등)은 건드리지 않습니다.

[사용법 - 3단계]
1. 압축을 완전히 풀고, 폴더 안의 파일을 한 곳에 그대로 둡니다.
2. 게임과 스팀을 완전히 끕니다.
3. START_MapMod.bat 을 더블클릭 -> 1번 -> y 를 누릅니다. "끝!" 이 나오면 스팀에서 새 게임을 시작하세요.

[꼭 알아두세요]
- 반드시 새 게임을 시작하기 전에만 적용하세요. 진행 중인 세이브에는 쓰지 마세요 (지도가 달라집니다).
- 다시 1번을 실행하면 지도가 새로 섞입니다. 2번(시드 지정)에 같은 숫자를 넣으면 같은 지도가 나옵니다.
- 게임이 업데이트되면 같은 방법으로 다시 실행하세요.
- 원래대로: START_MapMod.bat -> 3번. (원본은 게임 폴더의 AssetBundles\_mods_backup 에 자동 백업됩니다.)

[필요한 것]
- Windows, Python 3 (https://www.python.org/downloads/ 설치할 때 "Add python.exe to PATH" 체크).
- 처음 한 번 인터넷으로 UnityPy 가 자동 설치됩니다.
- 게임 폴더는 자동으로 찾습니다. 못 찾으면 경로를 붙여넣으라고 물어봅니다.

[문제가 생기면]
- 화면 메시지와 같은 폴더의 apply_all.log 를 보내 주세요. 실패하면 게임 파일은 바뀌지 않습니다.
- 게임 파일을 수정하는 비공식 도구입니다. 사용은 본인 책임이고, 이상하면 3번(되돌리기) 또는 스팀의 "게임 파일 무결성 검사"로 원상복구됩니다.
