# 공유판(ItD_MapOnly)과 일반판(ItD_MapMod)의 차이 보고서

기준: 브랜치 `claude/game-ammo-recipe-mod-kknjko`, 코드 기준 확인(빌드 #104 시점). 게임 안에서 직접 확인한 것과 코드로만 확인한 것은 7장에 구분해 적었습니다.

## 1. 한눈에 보기

| 항목 | 일반판 `ItD_MapMod.exe` | 공유판 `ItD_MapOnly.exe` |
|---|---|---|
| 용도 | 내가 쓰는 전체 도구 | 다른 사람에게 주는 단순판 |
| 창 | 큰 창(900×1038), 옵션 체크 29개, 로그 창, 프리셋 도구 버튼 | 작은 창(580×647), 체크 2개 + 시드 칸 + 버튼 2개, 로그 창 없음 |
| 선택지 | 거의 전부 선택 | **"랜덤 지도", "랜덤 특성" 두 개만** 선택, 나머지는 강제 |
| 게임 실행 파일(`GameAssembly.dll`) 수정 | 선택한 항목만(최대 5종) | **항상**(스테이션 휠 금색 + 지도 패널) |
| 새 게임 전용 | 그렇다 | 그렇다 |
| 실행 파일 형태 | 콘솔 exe(검은 창은 숨김) | 창 전용 exe(검은 창 없음) |

## 2. 공유판에서 고정/선택되는 내용

**항상 적용 (선택 불가)**
1. 탐색 반경 1.5배
2. 스테이션 휠 금색 강조 (DLL 수정)
3. 지도 패널 "추천/탐색/근접/사격/정신" 탭, 작업 중인 생존자 숨김 (번들 + DLL 수정)
4. 랜덤 지도를 켠 경우의 부속 처리: 교역소 5곳 중앙 이동, 거점 16곳 섞기, 유출구역 세트 이동, 어둠의 심연 사우스버러 조건 보정

**선택 (체크 2개)**
- **랜덤 지도** (기본 켬): 지도 건물 위치 섞기. 끄면 위 4번도 같이 꺼지고 탐색 반경만 넓어집니다.
- **랜덤 특성** (기본 끔): 생존자 시작 특성 섞기. 켜면 "무술가/프로레슬러 특성 보유자 4티어 맨손격투 전문가 보장"이 함께 적용됩니다. 스킬 트리 섞기는 포함하지 않습니다.

## 4. 건드리는 게임 파일

| 파일 | 일반판 | 공유판 |
|---|---|---|
| `data_levels` (지도 좌표) | 지도 섞기, 탐색 반경 | 같음 |
| `data_config` | 베일/상인 항목, 좀비, 연애 등 선택 항목 | 내용은 수정하지 않음(백업·원본 유지, 읽기만) |
| `data_balancing` | 선택 항목 다수 | 어둠의 심연 보정, 랜덤 특성/맨손격투 보정(켠 경우) |
| `ui_screens` (50MB 번들) | 지도 패널, 시나리오 버튼(선택) | 지도 패널 |
| `loc.korean`, `loc.english` | 장소 설명, 패널 "추천" 라벨, 시나리오 버튼 라벨(선택) | 패널 "추천" 라벨 (영어 파일은 백업만) |
| `data_visual` (530MB) | 맨손 처형 효과음(선택) | 건드리지 않음 |
| `GameAssembly.dll` | 선택한 DLL 항목(최대 5종: 문 엿보기, 휠 금색, 거점 이동, 랜덤 시작, 패널) | 휠 금색 + 지도 패널 코드 |

공통: 적용할 때마다 항상 원본에서 다시 계산하고, 원본은 `AssetBundles\_mods_backup`(번들)과 `GameAssembly.dll.bak`(DLL)에 백업합니다. 되돌리기 버튼이 이 전부를 원상 복구합니다.

## 5. 공유판의 제약과 위험

- 이 게임 빌드 전용입니다. 게임 업데이트나 스팀 "게임 파일 무결성 검사"가 있으면 풀리고, 다른 빌드면 DLL 단계에서 아무것도 바꾸지 않고 중단합니다.
- **DLL을 고칩니다.** 받는 사람의 게임 실행 파일을 수정하는 것이므로, 안내가 필요합니다. 이번 요청으로 앱 안의 확인창에서 이 설명 문단을 뺐습니다. 지금 이 사실을 알려 주는 곳은 README뿐이고, README의 위쪽 목록은 아직 이 내용을 반영하지 않았습니다(6장).
- 지도 섞기의 한계(핀만 움직이고 지도 그림은 그대로, 망원경 목록은 근사)는 두 판이 같습니다.
- 두 판 모두 새 게임 시작 전에만 쓰는 것이 원칙입니다.

## 6. 정리가 필요한 점 (공유판 README)

`README_SHARE_MAP.txt`가 현재 상태와 맞지 않습니다.
1. 위쪽 "무엇이 바뀌나요"에 "지도와 무관한 항목이 들어 있지 않습니다"라고 되어 있는데, 지금은 스테이션 휠 금색과 지도 패널(DLL/UI 수정)이 포함됩니다.
2. "사용법" 3단계가 옛 메뉴(1번, y)로 적혀 있습니다. 지금은 창에서 [적용] 버튼을 누르는 방식입니다.
3. DLL 수정 사실은 맨 아래 덧붙인 문단에만 있습니다.

원하시면 이 세 곳을 현재 상태에 맞게 고치겠습니다(이번에는 요청하지 않으셔서 건드리지 않았습니다).

## 7. 검증 상태

| 확인 수준 | 내용 |
|---|---|
| 게임에서 확인됨 | 지도 섞기와 탐색 반경(이전 공유판), 지도 패널(섞기 켠 새 게임에서 나옴), 시나리오 설정 화면의 버튼과 경고 제거, 랜덤 시작, 상인이 오긴 옴 |
| 일반판에서 쓰고 계신 것으로 알고 있으나 제가 직접 확인하지 못함 | 스테이션 휠 금색 강조 |
| 코드/시험으로만 확인 | 공유판 인자 조합(체크 조합별), 되돌리기, 속도 개선 후 결과 동일성(파이썬 직접 실행 기준), 맨손 크리티컬 값 변경, 상인 확률 제거 데이터 |
| 아직 확인 못 함 | 공유판 exe로 실제 게임에 적용했을 때의 전체 흐름, 콘솔 창이 번쩍이지 않는지, 크리티컬 10%의 체감, 상인 방문 간격, "무술가 포함 뽑기"의 후보 포함 보장(여러 번 시험 필요) |

## 8. 공유판에 넣을 수 있는 후보 (현재는 넣지 않음)

일반판에만 있는 항목 중 필요하면 공유판에 강제로 넣을 수 있는 것: 상인 방문 확률 제한 해제, 맨손 크리티컬 10%, 스킬 트리 랜덤, 문 엿보기 등. 공유판은 선택지를 두 개로 유지하기로 했으므로, 넣는다면 "강제 항목"으로만 추가됩니다. 항목마다 DLL/번들 수정이 늘어나는 점을 고려해야 합니다.
