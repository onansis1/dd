## 옵션 (명령줄)
`--seed N` 지도 시드 / `--vale random|crossbow|s12riot|none` 미스터 베일 신규 판매 품목 순서 (기본 random: 첫 품목 석궁/샷건 50:50, `none` 이면 끔) / `--romance` (명령줄 전용, 메뉴에서는 뺌) 공용구역 로맨스 아이템을 3명 이상에서도 사용 가능하게 - 연애 시도는 게임 코드가 2명만 처리하는 것으로 보여 3명 이상에서는 아이템만 소모될 수 있음 / `--romance-all` 연애의 모든 제한 해제 (정확히 2명일 때 적용. 3명 이상 허용은 `--romance` 를 같이) (가족/나이대/연애 중 조건, 호환성 속성 6종(나이대·성적 지향·실연·입냄새·연애 대상 여부·관계 단계), 성공 확률 구성 값(관계 단계별·아이템 21종)을 최대로) / `--zombie` 탐험 중 죽은 생존자가 좀비가 될 확률 50% -> 100% + 예외(첫 이탈자/좀비 아닌 것에게 죽음) 전부 해제 + 강제 좀비화. 깊은 상처 감염 좀비화는 별개 경로라 그대로. 좀비화 실제 처리는 게임 코드라 게임 내 동작은 미확인 / `--quiet-steps` 생존자가 걷거나 달려도 발소리 소음 없음 (웅크릴 때와 같게. 문/루팅/전투 소음은 그대로, 게임 내 동작 미확인) / `--hod-start` 어둠의 심연 필요 단서 수를 0으로 (시작부터 열리게 하는 시도, 게임 내 동작 미확인) / `--move-posts` 교역소 5곳을 지도 중앙부로 옮겨 모든 거점의 같은 반경 안에 교역소 1곳 이상 (`--posts` 는 모자란 거점의 반경을 늘리는 대안 방식) / `--trader-start 0|7` 상인 첫 등장을 사이클 10 -> 게임 시작부터 또는 7 / `--leads 1` 탈출 퀘스트 필요 단서 수 (run_all.bat 기본 1, `--leads 3` 이면 원래대로) / `--shuffle-shelters` (실험적) 메사냉방/치프웨이즈를 뺀 거점 16곳끼리 위치 교환 - 데이터 검증은 시드 6개로 통과했으나 스토리 충돌 여부는 게임에서 미확인 / `--no-shuffle` 반경만 / `--ammo 5 --inv 24 --corpse 24 --radius 1.5 --slots 2` 수치 변경 / `--restore` 복원

## Windows + Python 3.14 에서의 접근 위반(access violation) 대응
증상: `단계 실패: patch_balance.py (종료 코드 3221225477)` + `Windows fatal exception: access violation` + `TypeTreeHelper.py ... in read_typetree`.
원인: UnityPy 의 C 가속 모듈(UnityPyBoost)이 일부 환경(Windows, Python 3.14)에서 일부 오브젝트를 읽다가 죽습니다.
조치: 모든 스크립트가 시작할 때 가속 모듈을 끄고 순수 파이썬 읽기 경로를 사용합니다 (`read_typetree_boost = None`).
검증(이 환경): 가속 ON/OFF 로 만든 결과 파일이 balance/levels 모두 바이트까지 동일합니다. 전체 적용 소요 시간 약 27초.

## 미스터 베일 신규 판매 품목 순서
원래는 20사이클 단위 구간(20-40, 40-60, ... 180+)을 R77 권총 -> 석궁 -> S12 Riot 샷건 순으로 돌아가며 사용합니다.
품목이 열리는 이벤트(NewItemForSale)와 상점 재고가 같은 구간 조건(`Trader_MrVale_NewItemSale_*_CycleRange`)에 묶여 있어서, 이 구간 배정만 바꿉니다.
- 첫 품목은 석궁/샷건 중 무작위(50:50)이고, 이후 구간마다 다른 쪽이 열립니다 (석궁이면 다음은 샷건, 샷건이면 다음은 석궁). R77 권총은 이벤트도 재고도 끕니다.
- `--vale-start 20` (원래): 20-40 X, 40-60 Y, 60-80 X, 80-100 Y, 100-120 X, 120-140 Y, 140-160 X, (160-180 없음), 180+ X 상시. 볼트는 석궁이 첫 품목이면 20부터, 두 번째면 40부터(원래).
- `--vale-start 0|10`: **일정 전체를 20사이클 앞당긴다.** 0 -> 0-20 X, 20-40 Y, 40-60 X, 60-80 Y, 80-100 X, 100-120 Y, 120-140 X, (140-180 없음), 180+ X 상시. (10 이면 첫 구간이 10-20). 볼트는 석궁이 처음 팔리는 시점부터(석궁이 첫 품목이면 10, 두 번째면 20).
- 이전 버전은 시작 0 에서 첫 구간이 0-40(40사이클)로 길고 볼트가 사이클 10부터 석궁과 무관하게 팔려서, 석궁 없이 볼트만 보이는 구간이 있었다 -> 위 방식으로 수정.
- 무작위 선택은 이 도구를 실행할 때 한 번 정해진다. `--vale crossbow` / `s12riot` 로 고정 가능.
- 게임 안에서의 실제 동작은 확인하지 못했다 (데이터 수준 검증만).
