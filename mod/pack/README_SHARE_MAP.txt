Into the Dead: Our Darkest Days - 지도 도구 (지도 랜덤 배치 + 탐색 반경 1.5배)

[무엇이 바뀌나요 - 선택 없이 항상 아래 내용이 적용됩니다]
- 은신처 주변 탐색 범위(지도의 원)가 1.5배로 넓어집니다. 모든 거점의 원 크기가 같습니다.
- 지도의 건물/장소 위치가 무작위로 섞입니다 (은신처, 상인, 스토리 장소는 제자리).
- 교역소 5곳을 지도 중앙부로 옮겨(그 자리에 있던 장소와 서로 위치를 바꿈), 모든 거점의 같은 크기 원 안에 교역소가 1곳 이상 들어가게 합니다.
- 메사냉방과 치프웨이즈를 뺀 거점 16곳이 서로 위치를 바꿉니다.
- 이 배포판에는 지도와 무관한 항목(탄약/가방/상인/연애/좀비 등)이 들어 있지 않습니다.
- 주의: 이 도구는 항상 원본에서 다시 계산합니다. 다시 실행하면 지도가 새로 섞입니다.

[사용법 - 3단계]
1. 받은 zip 을 풀면 ItD_MapOnly.exe 가 나옵니다 (바탕화면 등 아무 곳에 두면 됩니다).
2. 게임과 스팀을 완전히 끕니다.
3. ItD_MapOnly.exe 를 더블클릭 -> 1번 -> y 를 누릅니다. "끝!" 이 나오면 스팀에서 새 게임을 시작하세요.

[꼭 알아두세요]
- 반드시 새 게임을 시작하기 전에만 적용하세요. 진행 중인 세이브에는 쓰지 마세요 (지도가 달라집니다).
- 다시 1번을 실행하면 지도가 새로 섞입니다. 2번(시드 지정)에 같은 숫자를 넣으면 같은 지도가 나옵니다.
- 게임이 업데이트되면 같은 방법으로 다시 실행하세요.
- 원래대로: ItD_MapOnly.exe -> 3번. (원본은 게임 폴더의 AssetBundles\_mods_backup 에 자동 백업됩니다.)

[필요한 것]
- Windows 64비트 PC 와 스팀에 설치된 게임. 그 외에는 아무것도 필요 없습니다 (Python, 인터넷 불필요).
- 게임 폴더는 자동으로 찾습니다. 못 찾으면 경로를 붙여넣으라고 물어봅니다.
- 처음 실행할 때 윈도우가 "PC를 보호했습니다 / 알 수 없는 게시자" 경고를 띄울 수 있습니다.
  서명이 없는 개인 제작 프로그램이라 나오는 경고입니다. "추가 정보" -> "실행" 을 누르면 됩니다.
  백신이 막으면 이 파일을 예외로 두거나, 믿기 어려우면 사용하지 마세요.

[문제가 생기면]
- 화면 메시지와 같은 폴더의 exe 와 같은 폴더에 생기는 apply_all.log 를 보내 주세요. 실패하면 게임 파일은 바뀌지 않습니다.
- 게임 파일을 수정하는 비공식 도구입니다. 사용은 본인 책임이고, 이상하면 3번(되돌리기) 또는 스팀의 "게임 파일 무결성 검사"로 원상복구됩니다.
