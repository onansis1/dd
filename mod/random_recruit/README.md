# 영입 생존자 무작위 섞기
`py -3 shuffle_recruits.py "<AssetBundles 경로>" [시드]` (게임/스팀 끄고 실행). 처음 실행할 때 data_balancing.bak 백업.

## 중요: 게임 규칙 때문에 '추천 영입 순서'가 있습니다
게임은 어떤 생존자를 영입하면 그 생존자의 **원래 장소**에 있는 NPC를 지웁니다.
그래서 장소 X에서 생존자 Y를 영입하면 Y의 원래 장소가 사라집니다.
- 모든 장소를 한 바퀴짜리 단일 순환으로 섞으면 15곳 중 **14곳**을 영입할 수 있습니다 (1곳은 영입 불가).
- 단, 영입 순서가 중요합니다. 실행하면 화면과 `recruit_order.txt` 에 나오는 **추천 순서대로** 영입하세요.
  (순서를 무시하면 평균 약 9.5곳만 영입 가능 — 시뮬레이션 결과)
- Bowman 은 섞지 않으며, 이미 섞인 상태여도 원래대로 복원합니다.
